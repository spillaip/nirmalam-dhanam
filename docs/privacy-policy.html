Nirmalam Dhanam Privacy Policy

Effective date: 24 August 2026

Nirmalam Dhanam is a local-first personal-finance application published by Nirmalam Group. This policy explains how the Android application handles data.

Data we handle

The app stores financial records that you enter, including Khatas, Vyavahara, Varga, Vyakti, investment balances, and optional descriptions. It also stores app preferences and the encryption salt required to derive the database key.

Storage and security

Financial records are stored on your device in a SQLCipher-encrypted database. The database is unlocked using a passphrase you provide. The app does not provide a forgotten-passphrase recovery mechanism. Android Auto Backup is disabled for the application database.

Collection, sharing, and retention

This release has no account sign-in, advertising SDK, analytics SDK, cloud sync, or server-side financial-data collection. Nirmalam Group does not receive or sell your financial records. Data remains on your device until you delete it, remove the application, or replace it by importing a backup.

Exports and backups

You may choose a destination using Android's system file picker to create a read-only JSON interchange report or an encrypted .ndf backup. JSON reports are plaintext and may contain sensitive financial information. .ndf backups contain an encrypted database payload. You are responsible for choosing a trusted destination and retaining your passphrase.

Optional Nirmalam AI (Bring Your Own LLM)

Nirmalam AI is disabled by default and is not a chat service. If you enable it, you choose an HTTPS OpenAI-compatible provider, model, and API key. The key is protected with Android Keystore and is not included in database or backup files. Only when you press one of the fixed insight buttons does the app send a minimised aggregate financial summary to that provider. The summary excludes raw transactions, payees, descriptions, and account identifiers. Your chosen provider processes that request under its own privacy terms.

Permissions

The public release requests vibration permission only for optional haptic feedback around cooling-tank actions. It does not request SMS, contacts, location, camera, microphone, or storage permissions. File access uses Android's system file picker.

Children

The app is not directed to children.
